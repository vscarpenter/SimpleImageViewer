# Combined image browsing

Approved October 11, 2026. Audience: Mac users browsing local image folders. Preserve StillView's existing neutral adaptive palette, SF typography, native controls and image-first layout.

Craft intent: product language, restrained variance (2). The signature is one combined collection with a collapsible folder tree, relative paths for duplicate filenames, and exact extracted text usable independently of AI descriptions.

Required states: direct folder; recursive scan with provisional count; completed combined collection; selected subtree; search matches/no matches; empty root with scope action; empty tree; partial child errors; canceled incomplete results; refresh retaining usable results; stale selection and changed image revision; disabled/unavailable description with available OCR.

Use a native source list for branch filtering, accessible selection and disclosure controls. All images restores the full collection. Branch counts include descendants. Keep the tree collapsible at narrow widths and preserve space for the image. Search matches filename and relative folder path without scanning or AI inference.

Verification includes native keyboard/control focus, actual grid row movement, text selection/copy, contextual menus and accessibility names. Existing Settings brief and Insights surface are preserved.
