# StillView Settings

## Product purpose
StillView browses local image folders and provides optional on-device image insights.

## Primary user
Mac users changing viewing defaults between browsing sessions, using a mouse, keyboard, or assistive technology.

## Principles
1. Use macOS conventions for settings navigation, controls, typography, colors, and focus.
2. Describe when each setting takes effect; keep live image processing separate from launch defaults.
3. Show only options with actual runtime behavior.
4. Keep privacy information close to image-analysis controls and scope claims to analysis.

## Success metric
A user can find and change an option in one compact pane, read all explanations without scrolling, and find a built-in shortcut by searching.

## Out of scope
- Viewer layout redesign and new appearance themes.
- Editable keyboard shortcuts or additional preference storage.
- Changes to image-processing behavior.

## User direction
2026-09-06: Replace the dark gray custom Preferences chrome with an interface following Apple's usability guidance. Favor native system treatment over decorative materials, cards, and animations.
